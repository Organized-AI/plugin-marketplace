# Axonometric Architecture Style Guide

## Grammar
Use axonometric architecture as a system metaphor, not a tilted flowchart. The hero object should look built: slabs, terraces, glass rooms, riser columns, bridges, cutaways, rails, blueprint grids, and measurement marks.

## Labels
Important labels live in flat screen-space. Use short card copy: one title plus 2-3 bullets. Add dark translucent backing behind small labels. Fit-check labels before final render.

## Palette
Default: background `#05080c`, surface `#090d14`, border `#18283a`, text `#d8e8f4`, gold `#f5d623`, cyan `#40c8e0`, green `#40c870`, purple `#a070f0`, orange `#f08040`.

## Motion
Grid wake -> base slab extrudes -> towers/rooms assemble -> packets/light travel -> labels reveal -> angular loop plate reveals -> optional logo/outro.
