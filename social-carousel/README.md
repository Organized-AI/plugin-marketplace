# Social Carousel

Codex/Claude-ready plugin scaffold for turning a source hook, proof stack, and brand asset into a clean social carousel with optional animated preview.

## Install

```bash
/plugin install social-carousel@organized-ai-marketplace
```

## What it simplifies

Instead of separately planning slide copy, rendering stills, auditing outputs, and then wrapping them in a quick animated preview, this plugin packages the workflow into one repeatable scaffold:

- source structure capture
- 6-slide storyboard logic
- branded still carousel
- contact sheet QA
- optional HyperFrames-style motion wrapper

## Included pieces

- `AGENTS.md` — operating rules for carousel builds
- `CLAUDE.md` — plugin overview
- `prompts/build-social-carousel.md` — reusable execution prompt
- `skills/social-carousel.md` — workflow reference
- `templates/social-carousel-starter/carousel-brief.json` — brief template
- `scripts/install_into_project.sh` — installer for project-local use
