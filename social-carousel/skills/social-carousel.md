# Social Carousel Workflow

Use this when a user wants a branded static carousel or an info-only post remix.

## Workflow

1. Capture the source structure: hook, proof, steps, CTA.
2. Condense it into 4–8 slides.
3. Choose a visual system that fits the source (clean-white, editorial-paper, or organized-dark style equivalents).
4. Render still slides deterministically.
5. Build a contact sheet for QA.
6. If requested, turn the stills into a short preview MP4 with simple motion.
7. Deliver contact sheet first, then slides, then MP4.

## Pitfalls

- Do not let the logo obscure footer or body copy.
- Do not use source screenshots when the user asks for info-only slides.
- Do not skip contact-sheet review.
