# Social Carousel Plugin

This plugin packages a simplified workflow for building branded social carousels from a hook, topic, proof points, and optional logo/brand mark.

## What it is for

- Instagram / LinkedIn carousel posts
- Creator/tutorial explainer slides
- “Info-only” remixes of reels or posts
- Optional HyperFrames-style animated preview wrappers

## Recommended workflow

1. Fill `templates/social-carousel-starter/carousel-brief.json`.
2. Use `prompts/build-social-carousel.md` as the execution brief.
3. Generate still slides first.
4. Export a contact sheet.
5. Only then make the optional animated MP4 preview.

## Deliverables

- `slides/slide_01.png` ...
- `contact_sheet.jpg`
- `manifest.json`
- optional `social-carousel-preview.mp4`
