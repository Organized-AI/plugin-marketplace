How to export from GTM
  1. Open the container in Google Tag Manager and go to Admin.
  2. Under Container, choose Export Container.
  3. Pick the version to audit (the live version, or your workspace), then Export.
  4. Drop the downloaded .json file above. For server-side GTM, repeat in the server container.

    Let AI tidy it

    This is GTM Autoresearch: a loop that proposes a change, re-runs the audit, and keeps the change only if the container got better. It tidies names and folders, the housekeeping nobody has time for.

    SuggestPropose one round of changes, such as filing every Meta tag in a "Meta" folder.
    Re-scoreApply them to a copy and run the same audit again.
    Keep or undoKeep only if the score rises and no check gets worse. Otherwise throw it away.
    AI can
    • Create folders
    • Move tags, triggers and variables into folders
    • Rename items
    AI cannot
    • Change tag settings or trigger rules
    • Delete anything
    • Publish. You import and review the result yourself.
