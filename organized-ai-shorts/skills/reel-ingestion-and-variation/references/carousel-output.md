# Carousel output mode

Use this mode when a Reel/Short should become a static companion asset for Instagram, LinkedIn, or similar feeds.

1. Capture the source argument as `hook → proof → mechanism → payoff → CTA`.
2. Condense it into 4–8 phone-readable 4:5 slides; one idea per slide.
3. Choose a visual system that matches the Short: Organized-dark, clean-white, or editorial-paper.
4. Render stills deterministically, then create a contact sheet before delivery.
5. If animation is requested, create a short fade/slide preview MP4 from the final stills.

Recommended slide structure:

- Slide 1: hook / claim
- Slides 2–5: evidence, mechanism, or steps
- Slide 6: practical takeaway
- Final slide: CTA and source note

Keep the mark clear of footer and body copy. Do not reuse third-party screenshots for information-only slides. Use the Reel’s `variance_map` so the carousel changes the copy, examples, visual assets, and CTA while preserving only the high-level argument.
