# Build a carousel from an Organized AI Short

Convert an approved Short/Reel brief into a phone-readable 4:5 social carousel.

Requirements:

- preserve the strongest source argument and the Organized AI point of view;
- condense the narrative into 4–8 slides with one idea per slide;
- use the same brand system as the Short, adapted for static reading;
- do not use source screenshots when the brief requests information-only slides;
- avoid text clipping, overlap, and logo collisions with the footer/body copy;
- output every slide and a contact sheet for QA;
- if requested, create a short fade/slide preview MP4 from the finished stills;
- return exact artifact paths and a concise change log.
